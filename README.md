## 🧑🏻‍💻 WEB IDE Chrome Extension 

### 🚀 목적
백준 온라인 저지 사이트에서 크롬익스텐션 형태의 웹 IDE를 통해, 편하게 ps를 할 수 있도록 하고 싶어서 만듦

### 🏃🏻 실행방법
1. `yarn build` 명령어 실행
2. `dist 폴더` 크롬익스텐션에 추가
